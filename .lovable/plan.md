# Landing page — Dra. Stefany Dias, Fisioterapia Dermatofuncional

Site de divulgação e agendamento para a Dra. Stefany Dias, fisioterapeuta formada pela UFES, finalizando pós-graduação em Fisioterapia Dermatofuncional.

## Identidade visual (baseada no cartão enviado)
- Paleta: rosa suave (aprox. #F5C6DA) e branco-creme, com listras verticais como elemento gráfico recorrente
- Tipografia: serifada elegante para títulos (estilo editorial, ex.: Cormorant Garamond / Playfair Display) + sans-serif leve para texto corrido
- Clima: delicado, profissional e acolhedor — estética de clínica de estética premium

## Páginas
1. **Início (/)** — foto profissional, nome, credenciais (UFES + pós em dermatofuncional), chamada para agendar
2. **Serviços (/servicos)** — lista de procedimentos com descrição e preço (microagulhamento, limpeza de pele, drenagem linfática etc. — conteúdo inicial de exemplo, fácil de ajustar)
3. **Sobre (/sobre)** — formação, foto, abordagem de trabalho
4. **Resultados e Depoimentos (/resultados)** — depoimentos de pacientes e espaço para antes/depois
5. **Agendamento (/agendamento)** — calendário online com horários disponíveis + botão de WhatsApp como alternativa
6. **Contato/Localização (/contato)** — endereço, mapa, Instagram, horário de atendimento

Botão flutuante de WhatsApp visível em todas as páginas.

## Agendamento online
- Habilitar o Lovable Cloud (banco de dados incluído, sem contas externas)
- Tabela de agendamentos: nome, telefone/WhatsApp, procedimento, data e horário escolhidos
- Página de agendamento mostra os horários disponíveis por dia; o visitante escolhe e confirma
- Área administrativa simples e protegida por login para a Dra. Stefany ver e gerenciar os agendamentos (confirmar/cancelar)
- Botão de WhatsApp como opção alternativa em todos os pontos de agendamento

## Fotos
- O usuário enviará as fotos profissionais; até lá, uso imagens ilustrativas geradas de alta qualidade como espaço reservado, já nos lugares certos para troca fácil

## Detalhes técnicos
- TanStack Start + Tailwind v4, rotas separadas para cada seção (melhor para Google/SEO)
- Títulos e descrições únicas por página, em português
- Site todo em pt-BR
